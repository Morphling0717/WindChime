风铃测试位于 `tests/backend.test.mjs`、`tests/frontend.test.mjs` 和 `tests/delivery.test.mjs`。它们验证：

- 探测并升级两站当前和无话题列的更早结构，保留 ID、slug、关联、时间、所有状态、屏蔽哈希、设置及宿主登录表；重复迁移不重复写入，失败回滚 DDL 和迁移记录。

- 公开 API 和 SSR DTO 不含内部备注、统计或身份；所有管理路径鉴权。待审核内容在列表与屏蔽摘要中隐藏，仅管理员详情显式读取。
- 话题快速切换、过期响应、退出权限、审核详情、双击投稿、失败保留草稿、切换后批量选中状态与操作状态；CSV 转义、媒体配置存储和客户端错误契约。
- 同步保留嵌套依赖与宿主文件，失败恢复旧产物；示例同源验证支持容器端口映射和反向代理 Host，并拒绝跨站写操作。

两站各自提供可重复执行的 `npm run test:mail:migrations` 与 `npm run test:mail`。HTTP 测试只允许 localhost，必须显式开启测试写入；应连接一次性数据库。命令和环境变量见各站 `docs/windchime.md`。

## 浏览器验证

使用 Chromium，检查桌面 1280 像素宽和移动端 390 × 844：

- 对照原版本截图，两站管理页保留各自背景、字体、颜色、布局、文案和导航；风铃内部 CSS 覆盖已移除。
- 两站原登录页可登录，首页入口可打开自定义投稿组件，实际投稿返回成功并保存。
- 二维码与海报按钮实际产生 PNG 下载，检查了图片内容；配色、背景、头像与品牌文字由网站提供。
- 无默认 UI 的独立示例完成投稿、登录、已读、收藏、新建话题、归档、恢复，以及二维码、海报、CSV 下载；管理页和话题投稿页可在移动端使用。仓库外演练使用独立依赖目录和真实压缩包，无跨仓 symlink；390 像素宽无横向溢出，浏览器无页面异常或控制台错误，退出登录后管理数据被清除。

联调额外加入临时测试模块，确认两个安装目录自动收到编译结果；再制造类型错误，确认保留旧产物；最后删除测试模块并确认两站产物同步删除。临时测试代码未留在源码或压缩包中。停止命令后只停止它启动的开发服务。

共同修复证据：最初两站的旧 JSON `password` 管理请求在共享校验中返回 400；仅修改风铃路由的鉴权后凭据剥离，再更新两站安装产物，同一 HTTP 回归均通过，没有再修改两份网站业务实现。公开字段过滤、归档和审核屏蔽摘要等修复同样只在风铃实现。

## 限制与未执行项目

- Docker 浏览器补测通过三者桌面/手机信箱操作和下载；Mia 既有 PWA `/app.jpg`、示例未提供的 `/favicon.ico` 有 404，细节见 Docker 记录。
- 数据验证是本地结构样本与故障注入测试，不能替代上线前对真实备份的迁移演练。
- Turnstile 验证器使用可控请求进行自动化验证；没有使用生产密钥完成真实 Cloudflare 挑战。
- Docker 已在外接 SSD 补测；GitHub Actions 尚未实际运行。Rosetta 下的 Linux/AMD64 验证不等于生产服务器性能或真实数据验证。
- UliUli 首页在手机宽度出现 `SongSystem` 动画属性的 React 水合警告，Next 开发错误标记可能盖住悬浮菜单。已在未修改的 `8d95177` 原版复现同一警告；`SongSystem`、`HomeClient` 文件校验值与原版一致。`/mail` 管理页和信箱操作未出现该警告。此问题最初另行记录，随后同日按用户要求在 UliUli 中修复了首屏状态及卡片动画复位，并通过手机长歌单、界面与干净生产构建检查；详见 UliUli 的 `docs/song-system-hydration.md`。
- npm 公开发布、线上部署、生产数据库迁移均不在本次执行范围。升级与备份、回滚步骤见 [迁移说明](MIGRATION.md)。
