# 展示主题与排版样板

使用共享 `WindChimeLiveCard`，与桌面和独立展示窗口复用实际渲染代码。

- 排版：经典信笺、文字双栏、横向条幅、弹幕侧栏、竖向信笺、居中短笺。
- 主题：纯净、UliUli 夜航、Mia 星祷。每个主题可以配任意排版。
- 默认展示 360 × 800 的弹幕侧栏。支持切换宽高、推荐尺寸、滚动速度、0–3 张横图/竖图、图片区域比例、横排/竖排/网格排列、长信和十八组合总览。选择排版保留当前尺寸，点击“使用推荐尺寸”才调整宽高；总览按各排版推荐比例显示。
- 图片固定在文字下方，按原比例完整缩放到图片区，始终可见。只有文字、链接文字和编号图片说明在剩余区域滚动到底，停留后回到顶部；短信静止，仅循环当前内容，不切换来信。框架、装饰和图片均保持固定。
- 字号支持 12–96px，可拖动滑块或直接输入数字；单张预览和十八组合同时使用所选字号，切换主题或排版保留字号。此处是离线预览，正式保存位于桌面「设置与外观 → 文字与配色 → 字号 → 应用外观」，展示外观磁贴也提供相同设置。
- 所有内容均为合成示例，没有管理授权或信箱连接。多图使用数字对应文字区内的图片说明。
- 主题名只在私人样板控制项出现，观众展示卡片不带 UliUli 或 Mia 品牌文字。

安装根目录与 `apps/desktop` 的依赖后，在仓库根目录运行：

```powershell
node scripts/build-display-designs.mjs
node apps/desktop/node_modules/electron/cli.js scripts/display-designs-smoke.cjs
```

输出 `.work/display-designs/WindChime-Display-Designs.html` 可双击在浏览器离线打开，是单一自包含文件。样板不加载远程字体、图片或脚本，也不向网站发送请求。截图和实际渲染验证报告在同目录。

2026-09-20 字号控件补充验证：重新构建样板后，在 Tabbit 实际操作数字框和滑块，确认即时渲染、12/96 边界联动、越界/空输入恢复、切换主题/排版/推荐尺寸保留字号、18 组合使用同一字号，以及图片仍在文字滚动区之外。桌面现有字号保存逻辑未改动。
