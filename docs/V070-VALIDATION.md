## 运行与升级

共享库：`npm ci`、`npm test`、`npm run pack:check`。桌面：在 `apps/desktop` 执行 `npm ci`、`npm run dev`；生产构建 `npm run build`；Windows x64 打包 `npm run make`。两站使用同一个固定 `vendor/windchime-embed-0.7.0.tgz` 与 lockfile，运行 `npm ci`、`npm run db:migrate`、`npm run build`。迁移前备份原数据库、媒体、环境配置及 Git 外资源。

新版网站 `/mail` 的“桌面连接”生成 30 天站点密钥，桌面导入后可选择所有现有及以后新建的活动。**旧密钥保持原来的单话题范围，需要重新生成一次站点密钥。** 桌面可撤销授权，生成管理授权仍由网页登录完成。

违禁词默认关闭，只能在桌面“设置”用站点密钥开启，对当前网站生效。关闭保留原词库和历史标记，历史命中原信回到私人普通收件箱。人工播出批准与违禁词开关、已读、收藏始终独立。
