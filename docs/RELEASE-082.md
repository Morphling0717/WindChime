# 风铃 0.8.2 修复与验收记录

功能验收日期：2026-09-20；发布与容量复核更新：2026-09-23（北京时间）。共享库与桌面均为 0.8.2，沿用已确认的玻璃界面、Logo、六种排版及 MIT 许可。实际安装、包启动、窗口采集和生产更新分别记录，不互相替代。

## 修复了什么

- **慢网络下列表一直刷新不出来**：周期刷新曾不断取消仍在进行的请求。现在后台刷新等待当前请求完成；主动操作仍会刷新，新话题不会接收旧话题的迟到结果。
- **连接失败却丢失当前选择**：连接、切换和移除现在先完成加密文件的原子保存，再切换内存状态及关闭旧输出。磁盘写入、重命名或加密失败保留旧连接。私人主窗口和磁贴的未保存稿在提交时统一检查，避免遗漏或重复确认。
- **旧浏览器配对迟到覆盖新连接**：绑定当前操作和网站版本，旧响应不能改回旧信箱。已兑换成功但本地保存失败的授权保留在本次配对内存里，用户可以明确重试；不会循环弹窗或重复兑换一次性凭据。
- **旧图片响应把新信件撤下**：图片成功及失败均绑定原展示、连接和快照版本；切换后的旧 409、超时和图片不能影响新画面。当前授权真正失效仍清空。
- **审阅图片尺寸错误**：私人预览读取已规范化图片的实际宽高，并正确取消旧加载、释放地址；预览和观众画面使用同一比例。
- **删除另一封信也清空正在播出的信**：数据库触发器只撤下受影响的当前快照，仍推进控制版本，防止旧上屏请求穿过修改。
- **撤销末尾信后“下一封”回到开头**：删除队列成员前保存其前驱位置，批量删除也保持正确进度。历史上已经丢失的位置按安全空白处理，主播可重新手动选择或结束展示后开始。
- **操作冲突提示一闪就消失**：轮询成功只清除连接错误，409 操作冲突保留到下一次明确操作或切换范围。不会自动重试上屏。
- **安装中断后的半安装状态**：玻璃向导保留，内部改用已校验的独立暂存目录、事务日志、目录切换和元数据恢复；故障注入覆盖进程在每个关键阶段退出及恢复时再次中断。完整实际安装往返仍需单独验收。
- **卸载遇到文件占用后无法重试**：先处理程序载荷，成功后才移除归属标记及卸载器；被占用时留下重试入口。旧的 DOS 8.3 注册路径和快捷方式按同一真实路径比较，避免把自己的旧安装误认成其他目录。
