# 风铃桌面控制台（Windows x64）

风铃桌面端是面向主播的私人审核与直播播控应用。你在私人控制台里拆信、审稿、控制上屏，观众端只展示你明确确认过的内容。

---

## 下载与安装

- **国内直连安装程序**：[WindChime-Setup-latest.exe](https://windchime.uliuli.cn/updates/WindChime-Setup-latest.exe)
- **GitHub Releases（含免安装便携 ZIP）**：[Releases 页面](https://github.com/Morphling0717/WindChime/releases/latest)

**覆盖升级说明**：已安装旧版时，直接运行新版安装程序覆盖安装即可，已保存的网站连接密钥、全局热键、深色模式与本地装饰不会丢失。`1.1.0` 起支持国内直连应用内自动检查、校验并一键更新。

## 常用操作速查

### 1. 导入连接密钥
1. 在你的提问箱网页后台（`/mail`）生成并复制「站点连接密钥」（默认 30 天有效，可多台电脑共用，随时可在网页撤销）。
2. 在风铃桌面端粘贴密钥并点击 **「使用密钥连接」**，即可在顶部自由切换网站与话题。
3. 密钥剩余不足 72 小时时，软件顶部会自动提醒你提前更换。

### 2. 配置 OBS / 直播姬
- **方式一：本机 OBS 浏览器源（推荐）**  
  在「直播工作台 → OBS 采集设置」开启本机服务（仅监听 `127.0.0.1`，不对外暴露），复制生成的地址粘贴到 OBS「浏览器」来源即可。无需打开独立展示窗口，支持真信、附图、测试卡、本机水印、滚轮同步与一键清空。
- **方式二：独立透明窗口捕获**  
  点击「打开独立展示窗口」，在 OBS 添加「窗口捕获」选择 `WindChime Display`（若出现黑屏，将捕获方式改为 `Windows 10 (1903 及以上)` 并取消勾选捕获光标）。窗口位置会在重启后自动记住。

### 3. 盲盒拆信与悬浮小窗
- **盲盒拆信（默认）**：待机无剧透，点击「拆下一封」仅在私人屏幕展开，附图默认模糊防突脸；支持快速打码、移出图片、一键「确认并直接上屏」、跳过拒绝或直接拉黑。
- **自定义偏好**：在「设置与外观 → 播控与热键」可按需开启「随机拆一封」按钮、「拆封下一封时先清空观众画面」、新来信风铃提示音、以及启动默认页。
- **悬浮小窗**：点击工作台右上角的 **「悬浮盲盒小窗 ↗」** 或 **「悬浮播控小窗 ↗」**，可将独立小窗置顶悬浮在游戏/画布角落操作。

### 4. 全局热键
- **`Ctrl + Shift + H`**：随时随地一键清空观众画面（固定保留）。
- **自定义热键**：在「设置与外观 → 播控与热键」可录制「下一封」与「向上滚动 / 向下滚动 / 暂停滚动」全局热键。

### 5. 外观、本机水印与播报复盘
- 在「设置与外观 → 展示外观」可切换 3 套主题与 6 种排版，下方还可上传仅存于本机的角落头像、频道文字水印与半透明背景叠图，实时预览并同步到展示端。
- 每次真实来信上屏会自动记录在本机复盘日志中，下播后在盲盒底部抽屉可一键导出 Markdown 或 CSV 清单，也可随时一键清空。

## 安全与隐私设计

- **只展示已确认内容**：程序启动、重启、休眠恢复或网络断开时，观众画面一律自动回到透明空白，绝不自动补播旧信。
- **凭据本机加密**：连接密钥由主进程通过 Windows 系统 `safeStorage` 加密存储，渲染界面与展示端均无法接触原始凭据。
- **更新双重校验**：内置 Ed25519 公钥验签与安装前 `SHA-256` 完整性复验，防止传输被篡改。

## 开发者：从源码运行与打包

环境要求：Windows x64，推荐使用 **Node.js 22 LTS**（打包工具链需要），并确保系统具备 .NET Framework 4.x（Windows 自带）。

```powershell
# 1. 在仓库根目录安装并构建共享库
npm ci
npm run build

# 2. 进入桌面端目录安装依赖并启动开发模式
cd apps/desktop
npm ci
npm run dev
```

常用测试与打包命令（在 `apps/desktop` 目录下执行）：

```powershell
# 运行桌面端单元测试
npm test

# 制作 Windows 安装程序 (.exe)、便携包 (.zip) 与 SHA256SUMS.txt
# 若临时目录路径包含中文，请指定纯英文目录：
$env:WINDCHIME_BUILD_ROOT = 'D:\WindChimeBuild'
npm run make

# 对生成的便携版执行独立启动与安全校验
node scripts/verify-portable.cjs
```

发布流程已集成在 [.github/workflows/release-desktop.yml](../../.github/workflows/release-desktop.yml)，推送 `v*.*.*` 标签即可在 GitHub Actions 自动完成测试、打包、GitHub Release 发布与国内镜像源签名同步。完整许可信息见 [docs/LICENSES.md](../../docs/LICENSES.md)。
