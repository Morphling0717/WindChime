# 风铃 0.8.3 验收记录（候选）

本轮桌面、共享库均为 0.8.3，两站固定同一新版 tgz。公开 API、授权范围和数据库结构没有新增。页面、安装器和预览样稿删除宣传口号，保留必要操作、错误和防误播说明；用户原信、上屏稿、保存的海报配置和许可证原文不改。

## 候选与证据

此前运行源码 47b03b2 的桌面候选因文案修改而作废保留，不用于本轮正式发布。旧证据见 [原候选记录](RELEASE-DESKTOP-083.md)，其中通过项不能代替本轮新包验收。

本轮最终提交、包摘要、共享及桌面测试、两站验证与原生验收将记录在 `evidence/0.8.3-copy/`。任何影响产物的后续修改均重新打包并重测受影响项。

## 成品门槛

- 共享库、桌面测试、压缩包独立安装检查、两站隔离构建和重复迁移、真实登录 HTTP 业务与权限回归。
- 窄窗口和高 DPI 下的新文案及玻璃界面；六种排版、主题、字号、固定图片、长文字循环滚动。
- 磁贴置顶、实际系统热键、未保存稿保护、断线重启和休眠恢复空白。
- 最终 EXE 在新隔离中文目录安装、快捷方式、注册信息、旧版本升级及合成配置保留、故障回滚、托盘卸载提示和正常卸载。
- 最终 ZIP 独立启动；实际运行的 EXE 和 ASAR 必须与最终载荷清单匹配。
- OBS 和直播姬分别实际窗口捕获，仅本地预览；正常隐藏响应后 1 秒内清屏，静默断线 3 秒内清屏。私人控制、登录及错误不能进入输出。

以上必要验收尚未全部完成，三个 PR 保持草稿，不提前合并或公开发行。
