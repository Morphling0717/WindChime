# 0.7.0：网页生成密钥，桌面完整管理

网站和桌面都应升级到 **0.7.0**。代码仓库升级不会替换正在运行的网站，需完成网站实际部署。普通桌面流程不依赖 B 站密钥、网关、H5 项目或上架。

## 连接

1. 按原方式登录网站 `/mail`，展开“桌面连接”，填写密钥名称并生成。
2. 将完整密钥粘贴到桌面“网站连接”中。它包含网站地址，无需再填地址；主进程验证服务端身份及权限后才保存连接。
3. 选择当前网站，再选择话题。站点密钥自动包含现在及以后新建的活动；可见窗口每 3 秒更新普通管理数据，恢复窗口及操作后立即刷新。
4. 在收件箱管理信件，在直播控制台审阅最终稿、批准进入待播，再手动上屏。直播软件只捕获 `WindChime Display`。

完整密钥只在生成时显示，不存入浏览器。切换话题、离开页面或退出登录会清除已显示的密钥。授权列表保留名称、范围、到期时间和撤销入口。密钥编码不是加密，不应公开或展示给观众。

## 范围、期限和撤销

新密钥范围是整个站点，自生成起 **30 天有效**，可重复导入及用于多台电脑，重复连接不会延长期限。同一电脑重复导入复用已有连接；导入失败保留原连接。凭据由桌面主进程使用系统加密保存，不保存网页登录密码或本地信件数据库。

**旧密钥仍只授权原来的单个话题。** 因此升级桌面后，旧连接不会自动出现其他活动。需要在新版 `/mail` 生成一次站点密钥，再导入桌面。旧的浏览器配对入口继续保留，也只授权网页登录时选定的话题。

管理密钥的范围由服务器决定，不能通过改密钥编码、话题参数或浏览器 Cookie 扩大。桌面可以查看和撤销密钥，不能生成、续期或提升管理权限。生成密钥及批准旧设备配对仍需要网页登录。

撤销一个站点密钥后，所有共用此密钥的电脑及其派生展示授权失效，其他密钥保持有效。展示凭据始终只读且限定一个话题；删除活动不会删除全站密钥。撤销管理密钥不会删除信件、已读、有效批准或排序。

## 违禁词设置

0.7.0 升级后默认关闭，即使原有词库或环境变量含有词语，也不会自动启用。唯一开关在桌面“设置”，标明对当前网站生效，只有全站控制密钥可切换。网页读取相同设置但不提供开关，网页 Cookie 也不能直接调用写接口。

关闭时服务端停止匹配，两端隐藏词库、命中标记及旧敏感词审核模块。历史命中信回到普通私人收件箱，正文、未读、收藏和计数正常；数据库保留原标记和词库。重新开启后恢复历史分类，只匹配此后的投稿，不扫描旧信。此开关不改变黑名单、人机验证、限流或人工播出批准。

## 升级、运行和错误提示

两站固定使用同一 `windchime-embed-0.7.0.tgz` 和 lockfile，先备份原数据库、媒体、配置及私有资源，再在副本重复运行迁移并比对原数据。保留数据库路径和现有哈希盐，包括显式空字符串。0.7.0 在事务中重建控制授权表以容纳显式范围与空站点 topic_id，保留原授权 ID、哈希、期限及父子关系；不能只手动加一个默认话题来代表全站权限。

密钥接口位于 `/api/mail/live/control/*`；网页旧 `/mail/live` 只跳转 `/mail`，并保留短期配对参数，不再是直播控制台。`capabilities.features.siteControl` 表示支持站点授权；`control/identity` 只返回服务端授权信息，不含信件。

接口未找到或返回 HTML 404 时，确认网站地址和线上版本；“旧话题授权”需要生成新站点密钥；无效、过期或撤销需网页登录生成新密钥。网络失败不覆盖已连接网站。首次打开、重启、断线恢复、话题切换均保持空白，直到新的手动上屏。
