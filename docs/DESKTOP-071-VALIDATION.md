# 桌面 0.7.1 话题选择修复

日期：2026-09-13。仅更新 Windows 桌面，共享库和 UliUli/Mia 继续使用 0.7.0。本次不部署网站、不迁移数据库。

## 原因与改动

0.7.0 在宽度超过 960px 时只提供侧栏下方的话题选择器；侧栏固定高度且不能滚动，应用允许 620px 高窗口，导致选择器落到可见范围外。窄屏有另一个选择器，先前测试还通过 DOM 修改了隐藏的侧栏选择器，因此没有检出这个视觉缺陷。

网站与话题改为页面顶部的单一选择条，收件箱、直播工作台及其他页面共用。读取中、读取失败或没有话题仍显示入口和状态；侧栏可以纵向滚动。原主进程校验、切换撤下和未保存稿确认流程保持不变；确认前保存用户选中的 ID，避免异步确认后读到已复原的 DOM 值。

旧话题密钥仍只允许原话题。选择条直接提示需在网页生成站点密钥才能访问其他话题，不能通过界面扩大授权。
