共享包在 6b53289 生成，83d284f 的干净工作区重新打包后字节完全一致：`windchime-embed-0.8.3.tgz`，31,415,194 bytes，SHA-256 `c1207a59e8a3d5f9fe9e4e9a6c1895250569f2985add9b08c9737d8170a8f865`。两站固定同一文件。原验证来源与重现来源分别记录，不将旧测试伪记为重新运行。

本轮证据保存在 [evidence/0.8.3-copy](evidence/0.8.3-copy/)。任何影响产物的后续修改均重新打包并重测受影响项。

## 当前受阻项

- 电脑控制工具拒绝启动本轮隔离安装的卸载器，返回 `product policy blocks this app`。没有改用命令行、其他入口或其他工具绕过；原有安装的历史清理拒绝同样没有重试。该测试程序已经正常退出，隔离安装目录暂保留。
- 用户已处理直播姬的系统授权弹窗。按应用 ID 启动未留下窗口，随后通过 Explorer 打开现有开始菜单快捷方式，7.54.0.10521 主界面已成功出现。电脑控制工具提示直播姬的 Windows 权限高于控制工具，场景按钮没有响应；未提权、改安全设置或换工具绕过。已请用户手动配置本地测试场景与展示窗口捕获；尚未完成实际采集验收，未开播。
