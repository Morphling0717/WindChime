# 悬浮磁贴与直播热键

本功能随桌面 0.8.0 发行，和展示主题、循环滚动一起使用；旧安装包不会因源码更新自动升级。安装与验证范围见 [0.8.0 发行记录](RELEASE-080.md)。

## 使用

在直播工作台的「悬浮磁贴」工具条，可以分别打开来信列表、审阅与预览、待播顺序、快捷播控、展示外观。每种模块最多一个窗口；再次打开会找到已有窗口。

磁贴默认置顶，可用右上角取消或恢复置顶。拖动顶部标题区移动窗口，拖动窗口边缘调整大小。大小、位置和置顶选择保存在本机；显示器拔掉后会把窗口放回可用屏幕。关闭并不撤销已保存的批准或排序。应用重启不自动打开磁贴、不恢复审阅选中项、不恢复观众画面。

磁贴和主工作台使用同一网站、当前话题与业务接口。来信列表选中某封信，会同步到主工作台和审阅磁贴。未保存的审阅稿切换前要确认；取消时保留原稿。关闭有改稿的磁贴或切换话题/网站也先确认，随后关闭旧磁贴并撤下旧输出。外观改动在点击应用前仅供私下预览。

观众仍应采集独立的 `WindChime Display`。磁贴是带原文、编辑控件和错误提示的私人窗口，标题以 `WindChime Private` 开头。置顶只影响桌面窗口顺序，不把私人内容加入展示窗口。

## 下一封热键

在「设置与外观 → 直播热键」输入组合键，例如 `Control+Shift+N`，或者点击「录制组合键」后按键，再点击「保存热键」。默认不设置；「清除热键」可以关闭它。固定的一键隐藏热键仍为 `Ctrl+Shift+H`，不能被下一封覆盖。

组合键保存成功后，即使焦点在其他应用也由主进程响应。热键被占用或设置保存失败时，保留先前有效设置并在私人界面提示。录制期间临时释放下一封热键，避免设置按键时意外播出；一键隐藏继续有效。失焦、离开设置或录制超时后恢复。

下一封命令会读取当前话题的最新服务端版本，只在本机展示窗口及服务端连接租期有效时执行；沿用共享服务的有序队列与版本冲突检查。快速重复触发不会堆积操作，隐藏、关闭输出和切换话题会取消尚未发出的旧操作。到队列末尾后清空，不循环下一封；长信的循环滚动只处理当前已批准快照。

实现依据：[Electron 全局快捷键](https://www.electronjs.org/docs/latest/api/global-shortcut)、[Electron 窗口 API](https://www.electronjs.org/docs/latest/api/browser-window)。快捷键可能被其他程序占用，界面依照注册结果显示是否成功。

## 开发与验证命令

需要先安装根目录和 `apps/desktop` 的依赖；在仓库根目录执行共享构建/测试后进入桌面目录：

```powershell
npm test
cd apps/desktop
npm run build
node --test tests/*.test.cjs
npm run test:tiles
```

`test:tiles` 使用临时 SQLite、真实共享服务及 HTTP 处理器、隔离桌面配置，随后在第二个独立 Electron 进程检查恢复行为。它不读取现有桌面凭据，也不调用安装/卸载程序。测试替换系统全局热键的注册层并调用真实生产回调，不向用户桌面发送实际按键；应与真实系统热键实测分开记录。

本机 `workspace.v1.json` 只保存磁贴几何/置顶与快捷键。管理凭据继续留在原系统加密存储，磁贴和输出窗口均不获得令牌。磁贴 IPC 按窗口身份、当前网站/话题和连接代数校验；输出窗口的只读预加载接口保持独立。
