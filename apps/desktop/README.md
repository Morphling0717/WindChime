# 风铃桌面控制台 0.8.1（Windows x64，发行验收中）

0.8.1 增加带安装步骤的玻璃风格向导及完整开源声明，并修复展示重连后的迟到请求和预览尺寸边界。已有功能和连接配置继续兼容。本版安装／卸载、最终发行与实际直播采集尚待独立验收，进度见 [0.8.1 记录](../../docs/RELEASE-081.md)。

0.8.0 提供[六种展示排版与固定图片](../../docs/DISPLAY-DESIGNS.md)、[置顶磁贴和下一封热键](../../docs/FLOATING-TILES.md)。可先打开[交互样板](../../examples/display-designs/README.md)比较横向和竖向排版。新的展示设置需网站服务也升级至风铃 0.8.0；桌面仍能连接旧站，但旧站不会开放不支持的外观保存操作。安装桌面不会自动部署网站。

- **排版与主题独立**：经典信笺、文字双栏、横向条幅、弹幕侧栏、竖向信笺、居中短笺，均可搭配纯净、UliUli 夜航、Mia 星祷；主题名称只在私人设置中显示。
- **文字滚动，图片固定**：长信和编号图片说明滚动到底，停留后回顶，始终只循环当前一封。图片保持原比例，固定在正文下方，支持横排、竖排、网格和图片区比例。
- **五种置顶磁贴**：来信列表、来信审阅、待播队列、播出控制、展示外观可分别打开私人悬浮窗口，移动、缩放、固定在其他应用上方。
- **下一封热键**：在设置中录制或填写全局快捷键。录制期间暂停下一封动作，松开组合键后恢复；一键隐藏继续使用 Ctrl+Shift+H。

主播在私人控制台审信，OBS 或直播姬只捕获 **WindChime Display** 窗口。程序直接连接兼容的风铃网站，不需要 B 站项目、密钥、主播身份码或接入网关。

信件、图片、审核、待播顺序和样式仍由网站服务器保存。这里的“本地桌面版”指本地运行客户端；连接网站和同步信箱需要联网。

0.7.1 修复较矮窗口中话题选择器落在侧栏可见范围外的问题。“当前网站 / 当前话题”统一放在页面顶部，收件箱、直播工作台等页面使用同一入口；已有 0.7.0 网站可直接使用，无需再次部署或迁移数据库。

0.7.0 使用网页生成的**站点连接密钥**，粘贴一次即可管理网站全部话题；网站连接和当前话题分别选择，新活动每 3 秒自动同步。旧话题密钥与设备配对仍可读取，界面明确标记其范围，不会自动扩大权限。完整版需要先部署风铃 0.7.0 网站，升级桌面不会自动部署网站。

历史版本 0.6.2 仅更新桌面与安装视觉；0.7.0 则需要同时升级网站服务及数据库结构。

0.6.3 使用已确认的琉璃风铃品牌文件，分别适配应用图标、托盘、导航和安装画面。更新只涉及桌面品牌资源；已有连接、审核及数据保持兼容。

## 液态玻璃界面

采用冰蓝、薄荷渐变、磨砂透明面板、细亮边与柔和反光。左侧分为收件箱、直播工作台、话题管理、投稿分享、设置与外观，另有网站连接入口。所有窗口宽度都在页面顶部切换网站和话题，窄窗口使用图标导航。话题列表读取中、读取失败或没有话题时保留选择入口并显示状态。离开未保存稿前需要确认，取消会保留原稿；确认切换后先撤下并关闭旧输出、取消旧请求，再使用新范围。

## 完整管理功能

- **收件箱**：全部/未读/收藏、搜索、计数、发送者标签、原文和投稿图片，单封/批量已读、收藏、删除及 CSV 导出。打开未读信自动标已读后仍保留正在阅读的原文。
- **直播工作台**：原信与独立上屏稿、图片替换、批准/拒绝/撤销、完整待播排序、预览、手动上屏/下一封。批准不播放，修改必须重新审核。
- **话题管理**：名称、公开说明、私人备注、开放时间窗、投稿开关、排列序号、归档、全部已读并归档、恢复及永久删除。常规信箱不能归档或删除，最终限制由服务端执行。
- **投稿分享**：复用共享 `/media` 生成二维码与海报，实际保存 PNG；标题、文案、署名和本机头像按站点/话题保存在此电脑，重启保留。头像由用户通过原生文件选择器提供，主进程校验、缩放并重新编码，渲染器不抓取网络图片。
- **设置与外观**：全站屏蔽列表/解除屏蔽、敏感词开关/词表、已有控制授权列表与撤销，以及展示样式。桌面不能创建或续期控制密钥。

敏感词辅助审核默认关闭；关闭时隐藏相关模块和标记，新信不因此分流，历史原文仍保留。开启后可以私下读取待审原文、标已读、清除标记、删除或屏蔽发送者。旧话题密钥从当前话题响应读取开关，不请求全站设置。已读、收藏与清除敏感词标记均不代表批准播出。

“一键隐藏”和“结束展示”固定在顶栏，长信滚动时仍可操作。“一键隐藏”也保留托盘与快捷键入口；快捷键被其他程序占用时，私人界面会明确提示。

玻璃效果在应用内部渲染，不透出其他桌面应用。减少动态效果、减少透明度和系统高对比度偏好有对应样式。换肤仅作用于私人控制台，观众展示窗口继续使用主播配置的字体、颜色、布局和透明背景。

0.8.1 安装包使用同一 Logo 与玻璃风格窗口，提供欢迎、开源许可、安装选项、安装进度和完成页面。安装选项可选择位置与快捷方式，确认点击“安装风铃”后开始。读取、校验阶段显示实际进度；安装引擎未提供准确进度时显示进行中状态。Windows 权限与安全弹窗由系统呈现。旧 0.8.0 的 Squirrel GIF 安装过程仅作为历史版本保留。

## 安装和运行

构建产物位于 `out/releases/0.8.1/`：`WindChime-Setup-0.8.1.exe` 是安装向导，`WindChime-win32-x64-0.8.1.zip` 是便携版，解压后运行 `WindChime.exe`。文件摘要见同目录 `SHA256SUMS.txt`；此前版本保留在各自版本目录。当前没有默认 Windows 代码签名或自动更新；文件已生成、包校验、便携启动和安装／卸载分别记录，不能互相代替。

安装前先保存未完成的稿件，并通过旧版托盘“退出并结束展示”退出风铃。新版安装位置与旧版分开，沿用 Windows 加密的连接配置，不自动清理旧安装。新版快捷方式名为“风铃 WindChime”；确认新版正常后，再从 Windows 已安装应用区分版本卸载旧版。不要删除信箱数据库、个人配置或旧版目录来解决安装提示。

从源码运行：先在 WindChime 仓库根目录执行 `npm ci`，再执行：

```powershell
cd apps/desktop
npm ci
npm run dev
```

`npm run build` 构建界面、图标及运行时许可清单；`npm run make` 生成 Windows x64 安装包、ZIP、校验和及构建信息。运行包继续由 Electron Forge 白名单打包，安装器使用 WPF 玻璃向导和 NSIS 安装引擎。首次 make 需要下载并核对固定摘要的安装器组件与对应源码；这不会把平台密钥加入桌面。中间输出放在独立英文临时目录；若临时目录含非 ASCII 字符，可设置 `WINDCHIME_BUILD_ROOT=C:/WindChimeBuild`。Windows 构建机还需要 .NET Framework 4.x 的 WPF 编译器与引用程序集；脚本使用系统 Framework64 目录，主播无需额外安装 Node.js。

图标源为 `assets/branding/windchime_logo` 内的用户确认资产。大尺寸使用玻璃应用图，16–32 像素图标和托盘使用同源简化图形；导航 SVG 原样复制，安装动画保留完整琉璃中英组合。具体映射见 [品牌说明](../../assets/branding/README.md)，品牌历史验收见 [BRAND-VALIDATION.md](../../docs/BRAND-VALIDATION.md)，0.7.0 验收见 [V070-VALIDATION.md](../../docs/V070-VALIDATION.md)。

0.7.1 话题选择修复与本次验证见 [DESKTOP-071-VALIDATION.md](../../docs/DESKTOP-071-VALIDATION.md)。

打包后可运行 `node scripts/verify-package.cjs <make 输出的临时目录>`，只读核对运行文件、发行校验和、安装器资源与许可清单；该命令不执行安装器。风铃采用 [MIT License](../../LICENSE)，完整第三方组件说明见[许可与分发声明](../../docs/LICENSES.md)。

## 使用连接密钥

1. 将网站升级到风铃 0.8.1，在网页 `/mail` 沿用原有管理员登录。旧 0.7.x 站点密钥仍可管理已有信箱，完整外观需要 0.8.0 及以上服务，重连时拒绝迟到上屏请求需要 0.8.1 服务。
2. 在网页连接密钥入口填写名称，生成并复制站点密钥。网页显示授权范围、名称和准确到期时间。
3. 打开桌面“连接其他网站与信箱”，将完整密钥粘贴到“连接密钥”。核对“将连接到”的网站地址，然后点击“使用密钥连接”。程序向该站点确认实例、话题及授权身份，成功后进入相应私人工作台，并清除本次使用的密钥文本。
4. 在页面顶部的“当前话题”选择常规信箱或活动。收件箱与直播工作台共用这一选择，新活动每 3 秒自动同步。若下方显示“仅授权话题”，需在网页生成站点密钥后重新连接，升级不会扩大旧密钥权限。
5. 连接成功不会自动打开展示窗口或播放信件。之后按下一节完成私下审核与手动上屏。

连接密钥默认有效期 **30 天**，以网站显示的实际到期时间为准。同一密钥可在多台电脑重复连接；再次导入不会延长有效期。站点密钥允许管理网站全部话题，旧话题密钥仅允许原话题。请只交给可信任的控制端，不要粘贴到浏览器源或直播画面里。

网页只在当前页面内存中显示刚生成的完整密钥，刷新、关闭页面或切换话题后不再显示。丢失后可重新生成，并在“管理授权”撤销旧授权；点击“隐藏本页密钥”仅隐藏文本。**撤销同一授权会让共用该密钥的所有电脑失效**，相关展示也会撤下。桌面“移除此连接”只移除此电脑的保存记录，不替代网站撤销。

### 备用：旧版浏览器配对

展开桌面的“备用：旧版浏览器配对”，填写网站首页地址与连接名称，点击“在浏览器中登录并授权”。程序打开 `/mail?userCode=...`，在网站选择话题、核对配对码并批准。程序不保存网站管理员密码。配对过期后重新发起，不重复使用过期配对码。

0.6.0 站点还不能生成连接密钥，可先使用原有浏览器配对；网站与桌面都升级到 0.6.1 后再使用密钥流程。已有加密 v1 设备配置保持兼容，不需要清空数据或重新申请 B 站项目。

### 连接失败时

| 提示 | 处理方式 |
| --- | --- |
| 密钥格式无效或版本不支持 | 从网页重新复制完整连接密钥，勿只复制其中一段 |
| 密钥已过期或已撤销 | 在正确网站生成新站点密钥，再连接；旧密钥无法续用 |
| 网站尚未支持密钥连接 / HTTP 404 | 检查目标站点是否已部署风铃 0.7.0；旧站需要时使用备用配对 |
| 不属于当前网站实例 | 回到正确的网站重新生成，勿手动修改密钥中的地址或标识 |
| 无管理权限 | 使用网页管理员生成的站点控制密钥；只读展示授权无法管理 |
| 超时、无法连接或 HTTPS 错误 | 检查网络、网站运行状态和证书后重试 |
| 信箱选择已更新，旧请求已取消 | 确认当前信箱后重新操作 |
| 系统凭据加密不可用 | 恢复 Windows 系统加密能力后重试；程序不会回退为明文保存 |

所有错误显示在私人控制台，展示窗口保持独立。不要通过删除原信箱数据库或公开密钥来排查连接问题。

## 审核与展示

1. 私下查看原文，编辑最终展示稿；保存后明确批准。批准只加入待播列表，画面保持空白。
2. 点击“打开独立展示窗口”。直播软件添加窗口捕获，选择 **WindChime Display**。不要采集私人控制台或整个桌面。
3. 点击“上屏”或“下一封”才展示。最后一封后再次点下一封会清空，不循环。
4. “一键隐藏”、托盘菜单或 **Ctrl+Shift+H** 撤下画面。关闭私人窗口会留在托盘，托盘“退出并结束展示”才结束程序。

0.6.0 的既有 OBS 32.0.1 窗口捕获验收使用 Windows Graphics Capture、必须匹配窗口标题、开启“强制 SDR”、关闭捕获光标与音频，并将来源完整适配到场景画布。对应 `method=2`、`priority=1`、`force_sdr=true`。当时本机不强制 SDR 会出现颜色偏暗，按 exe 回退匹配则可能在展示窗口关闭后捕获私人控制台。该历史结果不代表 0.8.0 已经完成实机采集复验；私人磁贴窗口也不能用作观众输出。

请在正式使用前检查直播软件的本地预览。直播姬须单独验证，不能把 OBS 或 Electron 截图透明当作其他采集方式已通过的证明。完整截图、命令与限制见验收记录。

可以保存多个站点和话题连接。切换到其他连接、新密钥或新配对选中其他信箱时，先清空并关闭旧输出。有效批准、完整排序、已读和收藏保留；上屏不自动修改已读状态。

网页与桌面共用业务规则。修改正文、称呼、图片、图片说明或顺序会使旧批准失效，正在展示的信同步撤下。并发编辑明确提示冲突，保留未保存草稿。支持静态图片上传、透明背景、字体、字号、颜色、布局、图片排列和动画。

桌面每 500 ms 查询展示状态；共享库默认展示组件仍为 1000 ms，可通过 `pollIntervalMs` 在 250–1000 ms 内配置。正常网络下，远端隐藏还包含轮询与采集刷新时间；本机紧急隐藏不等待网站响应。

## 权限与旧版本升级

- 展示端只持有网站签发的只读授权，仅能取得当前获准播出的快照及图片。独立窗口没有管理 IPC、网站登录页或通知组件。
- 连接密钥的控制凭据由 Electron 主进程验证，通过 `safeStorage` 使用 Windows 系统加密，保存为 `devices.v1.enc`。导入后的完整凭据不回传给私人界面或展示窗口；旧版本 v1 配对仍可读取，旧 `gatewayOrigin` 和 `bindingId` 字段被忽略。
- 首次打开、重载、程序重启、恢复休眠或连接不确定时回到空白，直到新的手动上屏。没有待机时自动补播的任务。
- 桌面发行不处理 B 站启动参数，不连接平台会话，也不签发浏览器源链接。共享库仍可供其他网站配置独立展示页；网关与 H5 源码保留为另行启用的可选模块。
- 运行包采用文件白名单，不含 `.env`、平台密钥、测试数据或签名证书。
- 私人渲染器持久存储只用于显式海报偏好，不保存密码、控制密钥或收件箱。展示窗口仍使用独立临时会话，不读取私人偏好存储。

卸载可使用 Windows 的已安装应用入口。设备授权存储与程序文件分离；可在网站设备管理中撤销授权。本轮安装/托盘卸载是否完成，以实际验证报告为准，不把构建成功视为卸载已通过。

```powershell
npm run test:keys
```

这项联调需要浏览器测试驱动在两个真实网站的四个合成话题中生成连接密钥，再通过脚本输出的本机 loopback 内存桥提交；密钥不写入文件、命令行参数或日志。脚本随后启动两个具有独立临时配置的 Electron 进程，验证同一密钥重复连接、双端审核与播出同步、图片、草稿冲突、隔离、刷新和进程重启，最后等待浏览器撤销共享授权并检查两端失效。该命令会等待浏览器步骤，不能仅凭进程启动判断通过；以最终报告的 `passed` 结果为准。

可在已有的浏览器 Playwright 运行环境中调用 `scripts/key-smoke-browser.cjs` 导出的 `generateKeys(pages, bridge)`；`pages` 为已登录两站的 Page 数组，`bridge` 为本次脚本打印的 `fixtureBridge`。收到 `awaiting-browser-revocation` 后调用 `revokeSharedKey(pages, bridge)`，或在网页手动点击对应名称的撤销按钮。辅助函数只返回操作收据，不返回完整密钥。

实际 OBS 窗口采集脚本为 `scripts/capture-window.cjs`，需已有受密码保护的独立便携 OBS 实例；它使用真实网站的合成话题和桌面主程序，通过 OBS 正式 API 选择展示窗口并验证采集。脚本禁止启动推流、录制、虚拟摄像头或回放缓存。
