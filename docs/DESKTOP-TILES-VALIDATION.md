## 功能与故障验证

- 五种私人磁贴从工作台打开，每种只保留一个窗口；原生置顶可开关，位置和大小可保存。默认和最小尺寸下，下一封与紧急隐藏按钮都可见、可点击。
- 磁贴选信同步主窗口与审阅磁贴。未保存稿取消关闭/切换后保留；服务端并发改稿显示冲突并禁用旧保存，确认新版本后可保留本地编辑再保存。
- 批准只进入队列。手动上屏、隐藏、撤销批准、按顺序下一封及到队尾清空均通过，已批准队列保留。
- 磁贴不能导入密钥、切换全局连接/话题或修改系统热键，不能越过当前网站/话题。展示窗口没有控制桥接接口。
- 在信件 GET 未完成时关闭磁贴，迟到响应不能更改主窗口选信；GET 期间新增草稿会重新触发确认。关闭磁贴后迟到的展示授权不能打开新展示窗口，现有展示窗口不受磁贴关闭影响。
- 下一封热键读取最新服务端版本和有效连接，重复按键不堆积任务。快捷键占用/保存失败保留旧配置，隐藏后待处理操作失效。
- 录制组合键时临时释放下一封；候选键按下和修饰键未全部释放时，旧回调仍被抑制，全部释放后才恢复。固定隐藏热键保持有效。
- 第二个独立进程恢复磁贴位置/置顶和热键，但不恢复磁贴、选中信件或观众输出；未建立展示连接时下一封只给私人错误，不发送播放命令。
- 图片按可用宽度等比例放大，长文/长竖图在固定视窗内经过底部说明再回顶。装饰和边框固定；隐藏卸载整个卡片，普通轮询不重启滚动，快照变化才重置。

## 本轮发现并修复

原生窗口标题曾被共享 HTML 标题覆盖，改为固定私人磁贴标题；默认播控磁贴曾把隐藏按钮挤到屏外，改为紧凑双列按钮。输出配置高度大于实际窗口时曾裁掉尾部，已让真实展示入口限制卡片高度并按实际视窗滚动。

联调曾在隐藏后立即用另一磁贴的旧版本上屏，服务端正确返回并发冲突。测试现等待另一磁贴确认新状态后再手动上屏，不把旧请求拒绝误记为成功播放。展示进程安全替换期间，测试脚本的 DOM 探测曾挂在已销毁帧，改为有超时的探测；未修改产品的清屏规则。
