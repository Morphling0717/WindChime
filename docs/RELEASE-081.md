# 风铃 0.8.1 验收进度

记录日期：2026-09-20。共享库与 Windows 桌面代码均为 0.8.1。本页区分包构建与启动、真实安装／卸载及生产部署，以下只计入本轮实际证据。

## 变更内容

- 桌面安装采用玻璃风格向导：欢迎、MIT 许可原文、安装位置与快捷方式、进度、完成。明确点击“安装风铃”后才启动安装引擎。新目录与旧 Squirrel 目录分开，不自动卸载旧版；设备凭据格式及私人配置保持兼容。
- 项目继续使用原有 MIT 许可。根据 esbuild 实际捆绑输入收集 React、二维码等依赖的原始版权和许可；保留 Electron 自带的完整声明。NSIS 及插件保留各自许可、通知与对应原包/源码，具体见[许可说明](LICENSES.md)。
- 展示刷新或重连推进服务端控制版本，握手前准备的迟到“上屏／下一封”请求被拒绝。新窗口保持空白，已有健康窗口继续显示，主播新发出的手动命令才激活新连接。
- “展示宽度／展示高度”使用同一组渲染边界，私人预览与观众画面的实际尺寸一致；保留 0.8.0 的独立主题、排版、字号、文字滚动和固定图片。

运行、安装步骤和源码构建命令见[桌面 README](../apps/desktop/README.md)。

## 数据升级

0.8.1 不新增数据库结构，与 0.8.0 使用相同数据格式。网站握手修复必须随共享包部署，单独更新桌面无法改变线上服务端行为。两站继续使用原开发分支，UliUli 为 `codex/windchime-desktop-v0.6.0`、Mia 为 `codex/live-broadcast`，不合并 main。

更新前按既有流程保留环境、数据库、私有图片和未提交资源，并在副本上重复验证迁移。回退到 0.8.0 无需将外观转换成 0.7 格式，不得以升级前整库覆盖新投稿；服务重启后当前展示应保持空白。更早版本的回退限制见[0.8.0 记录](RELEASE-080.md)。
